## 저장소

| 저장소 | 역할 |
|---|---|
| `eventor-back` | Spring Boot API 서버 + SEO용 HTML(게시물 상세·카테고리·sitemap) + 문서 |
| `eventor-front` | React(Vite) 웹 앱. 정적 빌드를 nginx가 서빙 |

## 관리 원칙

- 기능·구조를 바꾸는 작업을 하면 관련 문서 절과 아래 변경 이력을 같이 고친다.
- 요구사항 단위의 상세 기록은 `worklog.md`, 구조·결정은 `migration.md`, 쓰는 기술이 바뀌면 `tech-stack.md`.
